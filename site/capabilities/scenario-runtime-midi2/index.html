Reframe Swift/MIDI2 scenario runtime.

Reframe can execute one tracked E2E contract through the owned Swift/MIDI2 runtime; independent acceptance evidence is still required.

Read the capability record → · Read the development method

What it establishes

A protocol-bound development capability.

The scenario actor discovers and invokes reframe.e2e.scenario.run, receives correlated lifecycle events, and drives the tracked contract through the same typed MIDI2 operation boundary as a software peer.

Current status

Executable. The contract and generic runtime are present; live acceptance is not yet claimed.

Required witnesses

AX, CoreGraphics/window-ID, FountainStore, MIDI2 trace, telemetry, and source provenance must agree.

Not established

No physical hardware, Bluetooth, unrestricted remote capacity, or released App capability is claimed.

Acceptance boundary

The next gate is independent proof.

The internal runtime cannot approve itself. A fresh isolated Store, bound Swift peer, target PID, window ID, executable, and source commit must carry the run through terminal classification before the status can change.
